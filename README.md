
# 📮 Speed Post Booking Web App

A **simple and intuitive Speed Post booking web application** deployed on **Vercel** that lets users enter sender/receiver details, calculate distance & weight, and pay using UPI — similar to checking postage charges on the Indian Post website. ([booking-website-v9ke.vercel.app][1])

👉 Live Demo: [https://booking-website-v9ke.vercel.app/](https://booking-website-v9ke.vercel.app/) ([GitHub][2])

---

## 🧾 Features

✅ Auto-generated article number
✅ Distance & weight calculation
✅ Input forms for sender & receiver details
✅ UPI payment QR integration
✅ Confirmation via UPI transaction note
✅ Simple and responsive UI

## 🎯 How It Works

1. User opens the booking page.
2. Enters **sender** and **receiver** details.
3. Provides **distance** and **weight**.
4. Clicks **Calculate** to see charges.
5. Scan the UPI QR code and complete payment.
6. Enter the UPI **transaction note** → then submit. ([booking-website-v9ke.vercel.app][1])
